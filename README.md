# Bang & Olufsen Landing Page

A responsive landing page inspired by Bang & Olufsen audio products, showcasing recommended items, product categories, brand story, and a contact section. Built to practice clean semantic HTML markup, responsive layout structure, and modular SCSS styling.

## Live Preview

- [Live Demo](https://oksana-zakharevych.github.io/bang-olufsen-landing/)

## Design Reference

- [Figma Design](https://www.figma.com/design/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?node-id=6817-212&t=GmifCWpPLrds5rru-0)

## Technologies Used

- HTML5
- SCSS / CSS3 (BEM methodology)
- JavaScript
- Gulp

## Getting Started

1. Clone the repository:

```bash
git clone [https://github.com/oksana-zakharevych/bang-olufsen-landing.git](https://github.com/oksana-zakharevych/bang-olufsen-landing.git)
cd bang-olufsen-landing
```

2. Install dependencies:

```bash
npm install
```

3. Run the project locally:

```bash
npm start
```

## Features

- Responsive layout adapted across mobile, tablet, and desktop viewports
- Structured sections for recommended products, categories, brand story, and contact details
- Slide-out navigation menu and smooth section scrolling
